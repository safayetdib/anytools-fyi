AnyTools is built with open source software. We list each library here with its license, and we add to this list as each tool is built.

- **Astro**, MIT License: builds the site's pages.
- **pdf-lib** 1.17.1, MIT License, by Andrew Dillon: reads, joins and splits PDF files in Merge PDF and Split PDF.
- **PDF.js** 6.5, Apache License 2.0, by Mozilla: draws page previews in Merge PDF and Split PDF.
- **fflate** 0.8.3, MIT License, by Arjun Barrett: packs the files from Split PDF into one ZIP.
- **Plus Jakarta Sans**, SIL Open Font License 1.1, by Tokotype: the lettering in the AnyTools logo.
